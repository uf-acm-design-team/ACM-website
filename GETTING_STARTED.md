# Getting Started Guide

Welcome to the team! Follow this guide to get your local development environment up and running for the UF ACM website.

---

## Prerequisites

Make sure you have the following installed on your machine before starting:
1. **Node.js**
2. **Git**
3. An IDE (code editor) like **VS Code**

---
