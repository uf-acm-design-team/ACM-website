# UF ACM Website (`uf-acm.com`)

Welcome to the official repository for the University of Florida ACM chapter website! This project is built by students, for students, aiming to provide a modern, fast, and scalable digital home for our community.

## 🎯 Project Purpose

The primary goals of this project are:
- **Community Hub:** Serve as the central platform for UF ACM events, membership info, officer bios, and resources.
- **Real-World Experience:** Provide newer student developers with hands-on experience working in an Agile team environment using industry-standard tools.
- **Performance & Design:** Deliver a lightning-fast, highly responsive web experience with a sleek, modern UI.
